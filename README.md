A modern, scalable, and highly modular **Airline Management System** built using a microservices architecture. This enterprise-grade backend manages core airline operations, passenger bookings, and scheduling, while actively integrating intelligent, next-generation automation.

---

## 🚀 Key Features

*   **Decoupled Microservices:** Independent services handling specific business domains (Booking, Flights, Users) ensuring zero tight coupling.
*   **Modular Architecture:** Designed deliberately to allow easy plug-and-play of new features without disrupting core workflows.
*   **GenAI Framework Ready:** Structurally optimized to introduce a dedicated **AI Chatbot Service** for automated ticketing and accessibility compliance.
