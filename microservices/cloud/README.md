# Cloud Infrastructure ☁️

This module acts as an aggregator for the infrastructure components required to run the Airline Management System in a distributed cloud environment.

## 🏗️ Upcoming Components

The following modules are planned for this aggregator:

1. **Service Registry (Eureka)**: For service discovery and registration.
2. **Config Server**: For centralized configuration management across all environments.
3. **API Gateway**: For unified entry point, routing, and cross-cutting concerns like rate limiting.

## 📂 Current Status

- **Type**: Maven Aggregator (POM)
- **Status**: Infrastructure setup in progress.
